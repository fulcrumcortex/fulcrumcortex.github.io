From a requirement to a reviewable change.

Skills behind the role

Make a reviewable code change

Investigate and implement a bounded software change in Fulcrum Code, preserving project conventions and validating the requested behaviour. Use for coding tasks in an existing project.

Expected output: A reviewable diff with behavioural validation and an accurate release status.

Access and verification

These are reusable procedures, not preconnected accounts. A drafting request stays a draft. If an external action is authorised, inspect its actual result before calling the task complete. A role name does not grant tool access, buy services or establish professional certification.
