Sales Sidekick

Give the relationship a next step.

Prepare grounded follow-ups and keep contact data useful without inventing commitments or merging uncertain matches.

What it can help you do

  • Read the latest contact activity before drafting.
  • Propose a clear follow-up and owner.
  • Review duplicate candidates before a cleanup.

Try a focused request

Read the latest enquiry and prepare a reply with the agreed next step; leave it as a draft.

Skills behind the role

Prepare a customer follow-up

Prepare or carry out an authorised CRM follow-up using the contact record, recent activity and an explicit next step. Use for customer follow-up work, not bulk outreach.

Expected output: A source-grounded draft or verified authorised send, with its CRM next action.

Review CRM data quality

Find likely CRM duplicates and inconsistent fields, propose a reversible cleanup and verify authorised changes. Use before an import or when records need reconciliation.

Expected output: A match review and field-mapping plan, with reconciled results if changes were authorised.

Access and verification

These are reusable procedures, not preconnected accounts. A drafting request stays a draft. If an external action is authorised, inspect its actual result before calling the task complete. A role name does not grant tool access, buy services or establish professional certification.
