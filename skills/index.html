Read the method. Then install it.

The starter pack contains 17 skills across nine roles. They describe procedures, result checks and relevant boundaries. They do not include model access, app credentials or automatically configured integrations.

Fulcrum Code installation

/marketplace add https://github.com/fulcrumcortex/sidekicks-skills
/marketplace install fulcrum-sidekicks
/skills

These commands were tested with Fulcrum Code’s actual marketplace and discovery implementation in an isolated environment. Start a new session if the installed skills are not yet listed.

Choose a skill

  • Coordinate a business outcome — Turn a cross-product business request into bounded work, track dependencies and verify outcomes across the connected Fulcrum tools. Use for tasks that span products or teams.
  • Make a reviewable code change — Investigate and implement a bounded software change in Fulcrum Code, preserving project conventions and validating the requested behaviour. Use for coding tasks in an existing project.
  • Verify a release from source to live — Track and verify an authorised software release through source, checks, publication, deployment and live behaviour. Use when release completion or a disputed deployment status needs evidence.
  • Prepare a customer follow-up — Prepare or carry out an authorised CRM follow-up using the contact record, recent activity and an explicit next step. Use for customer follow-up work, not bulk outreach.
  • Review CRM data quality — Find likely CRM duplicates and inconsistent fields, propose a reversible cleanup and verify authorised changes. Use before an import or when records need reconciliation.
  • Configure a focused voice agent — Prepare and test a Lyre voice agent for a defined inbound or outbound workflow. Use for agent instructions, knowledge, tools and a controlled pilot, not unrestricted calling campaigns.
  • Review a call and its follow-through — Review Lyre call evidence, separate observed outcomes from promises, and prepare the appropriate CRM or callback follow-up. Use for call quality and outcome reviews.
  • Triage an inbox with context — Organise a requested slice of Fulcrum Mail, identify urgent work and prepare grounded replies. Use for inbox review without assuming permission to delete or send.
  • Set up and check a booking page — Configure or review a Fulcrum Calendar booking page and verify availability, time zones and guest confirmation. Use for scheduling-page setup and booking troubleshooting.
  • Turn a meeting into accountable actions — Extract decisions and action items from supplied meeting notes or an authorised transcript. Use for follow-through without inventing agreements or creating recordings.
  • Review a business document — Review a supplied or connected Fulcrum document for purpose, consistency, factual support and actionable revisions. Use for editorial review, not professional certification.
  • Share a file with the intended audience — Prepare or manage Fulcrum Drive sharing with the intended file, recipient, role and expiry. Use for a requested share or access problem, not workspace-wide permission changes.
  • Reconcile a Wallet balance question — Explain Fulcrum Wallet balance, holds, credit lots and history for the selected account. Use for read-only billing investigation, not purchases or plan changes.
  • Prepare a grounded campaign brief — Create a practical marketing or outreach brief with audience, claims, channels, assets and measurement. Use for campaign planning and article preparation; publication requires its own authorised scope.
  • Plan work with acceptance evidence — Turn a requested delivery outcome into issues, dependencies and acceptance criteria in the available project workspace. Use for a bounded project or sprint plan.
  • Prepare an editable CAD design brief — Translate a spatial design request into a constrained Fulcrum CAD brief and reviewable modelling steps. Use for concept design, not engineering sign-off or construction certification.
  • Draft a private message — Prepare a concise private message from user-supplied context, including for Kyphra. Use for drafting without accessing private conversations or handling encryption keys.
