What are Sidekick skills?

A Sidekick is an AI teammate. A skill is a reusable set of instructions that teaches that teammate how to carry out a particular kind of work. Skills capture a process: when to use it, what context to gather, which steps to follow and how to check the result.

Example: preparing a customer follow-up

Read the customer record and recent conversation. Identify the agreed next step. Draft a concise reply. Check the details against the record, then ask for approval before sending.

This is an example of a skill procedure, not a claim that a downloadable follow-up pack is already available.

Skills guide behaviour. Connected tools and account permissions determine what an agent can actually access or change. Installing a skill does not give it access to your inbox, customer data or production systems.

01 / CONTEXT

Say when it applies

Give the skill a clear purpose and describe the information it needs before work begins.

02 / PROCESS

Write the steps

Capture the procedure, expected output and points where a person needs to review or approve an action.

03 / VERIFICATION

Check the result

Define evidence of success and what the agent should do when information is missing or a step fails.
