# Fulcrum Cortex GitHub homepage

Static homepage for https://fulcrumcortex.github.io/. Explains Cortex, Sessions and Sidekick skills and links to the product documentation.

Edit `index.html` directly. No dependency installation or build is needed. Keep skills availability statements aligned with the actual sidekicks-skills repository. Never publish private account data or credentials.

GitHub Pages source: `main` branch, root folder. `.nojekyll` serves the files directly. Root robots.txt links both this site and the documentation sitemap.

Preview: `python3 -m http.server 3190 --bind 127.0.0.1`. Check desktop and mobile layouts, keyboard navigation, local images and destination links before publishing.
