# Fulcrum Cortex GitHub homepage

Static site for https://fulcrumcortex.github.io/. Includes the homepage, nine Sidekick role pages, skills installation, suite and public profile directory.

No build or package installation is needed to serve the committed HTML. Edit the HTML and assets directly; keep the catalogue aligned with fulcrumcortex/sidekicks-skills/catalog.json. Each page has a canonical URL and structured page metadata. GitHub Pages serves main / root.

All screenshots are actual local Chat UI with fictional accounts and simulated API states. No user production screenshot or login credentials are published. Screenshot provenance is maintained in the documentation repository.
